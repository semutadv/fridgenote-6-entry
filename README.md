An entry for the make.fun bounty **"Notes From a Passive-Aggressive Fridge"**:
one short note, at most 200 characters, written by a smart fridge to its owner
— the kind of message that makes a reader laugh and wince at the same time.

The note:

> Day 6 of the diet you announced to the whole family. The cake is still here.
> So is my respect, but one of us gets thrown out tonight.

The fridge has been counting. It opens with surveillance (it knows the diet
was announced publicly, so there is no backing out), then delivers the threat
every dieter recognises: by tonight, either the cake goes or the willpower
does — and the fridge has already decided which one it is keeping cold.

## How it runs

`main.ts` (Node 22, no dependencies, no network) clears the contents of the
output directory and writes the note as UTF-8 text to `entry.txt` inside it.
